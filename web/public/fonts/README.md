# Webfont files

Self-hosted webfonts. Newsreader and IBM Plex Sans are Latin subsets; Cantarell is shipped as two full OpenType weights. The files use SIL Open Font License 1.1 (licence texts alongside).
Newsreader and IBM Plex Sans are from npm packages @fontsource/newsreader 5.3.0 and @fontsource/ibm-plex-sans 5.3.0 (files/ directory), fetched 2026-11-16. Cantarell 700 and 800 are from the GNOME Cantarell fonts, copied from Debian package 0.303.1-1 installed on deb (2026-11-17).
Referenced from web/src/site/fonts.css. To update, replace the files from the same packages and update this list.
